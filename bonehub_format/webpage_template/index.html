🚀 Getting Started

The database is a Hugging Face dataset repository in the BoneHub format. Download all of it or only the part you need, read it with the bonehub-format Python package, and cite the source datasets of the scans you use (each card under Source Datasets links to its paper and its entry in the BoneHub registry).

1Download

Everything, or one source dataset (here dataset 27):

pip install -U "huggingface_hub[hf_xet]"
hf download {{HF_REPO_ID}} --repo-type dataset --local-dir data
hf download {{HF_REPO_ID}} --repo-type dataset --local-dir data \
    --include "ds-0027/**" --include "index/*"

2Choose scans in the index

One row per scan, with its subject, labels, licenses and image geometry:

import pandas as pd
from huggingface_hub import snapshot_download

scans = pd.read_parquet("hf://datasets/{{HF_REPO_ID}}/index/scans.parquet")
chosen = scans[scans["segmentation"].apply(lambda l: "FEMUR_LEFT" in l)
               & scans["image_published"]]
snapshot_download("{{HF_REPO_ID}}", repo_type="dataset", local_dir="data",
                  allow_patterns=[f"{key}/*" for key in chosen["scan"]]
                  + ["ds-*/dataset.json", "ds-*/*/subject.json"])

3Read it in Python

Each scan has one segmentation per dataset that provided one:

pip install "bonehub-format[io] @ git+https://github.com/BoneHub/BoneHub-Format.git"

from bonehub_format import Database, read_segmentation

for scan in Database("data").scans():
    print(scan.key, scan.info.modality, scan.image_path)
    for dataset_id, path in scan.segmentation_paths().items():
        mask = read_segmentation(path)  # SimpleITK image of LabelMap values

Files under a restricted license are listed in the index but not in the repository (image_published and published columns); the cards below say where to obtain them.
